# AI-Agent CTF Web Workflow

Public collection of AI-agent workflows for solving CTF web machines and
everything related to the web in CTF — with Anthropic Claude, DeepSeek and
other models.

## Status

Collection complete (2026-11-20). Workflows first, then skills, then the full
routine — all built from the public resources below.

## Contents

- `COLLECTION.md` — all collected public workflows, repos, writeups, threads and videos, with links
- `collection.csv` — the same collection as a table (135 rows)
- `WORKFLOW.md` — the strong workflow, built step by step from the collected resources (CTF web machines)
- `ROUTINE.md` — the full step-by-step web security routine for every web target (scope → recon → map → login/sessions → inputs/APIs → prove → report)
- `skills/` — 8 public skill files copied verbatim (CTF web, solve-challenge, bug-bounty methodology, XSS, XXE, SQLi, JWT, browser exploitation), with install steps in `skills/README.md`

## How it was built

Research first, build second. Every resource here is public. Nothing here is
a live target or a private finding.
